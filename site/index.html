How it works

  • Fetches all open and upcoming IPOs from Upstox.
  • Creates one row per IPO.
  • Changes only FinInstrmId, TckrSymb, FinInstrmNm, and ISIN.
  • All other values come from the template row.
  • FinInstrmId is a unique random 6-digit number within each generated CSV.

Run manually

The secure manual trigger is kept inside GitHub Actions so the Upstox token never reaches this public website.

Open the repository's Actions → Generate IPO CSV → Run workflow.
